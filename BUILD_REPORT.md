**Conclusion:** This is a browser/PWA‑style React app, not a native mobile project. The
correct, App‑Store‑supported way to ship an existing web React app to iOS / Xcode is to
wrap it in a native shell. This project uses **Capacitor 7** (by the Ionic team), which
produces a *real* native Xcode project (`.xcworkspace`, `Podfile`, `Info.plist`, asset
catalogs) hosting the web build inside a `WKWebView`. No rewrite of the validated game
logic was required, and the result archives and submits to the App Store like any native app.

> Because the project is **not** Expo, an "Expo prebuild" does not apply. The Capacitor
> equivalent — `npx cap add ios` (native project generation) + `npx cap sync ios` — was run
> and is documented below.

## 5. Remaining warnings (non‑blocking)

1. **`@ts-nocheck` on `src/BrainKingdom.tsx`** — intentional (see Fixed errors #4). Type‑checking
   is disabled for this single game file only; `main.tsx`, config, and everything else are checked.
2. **Vite large‑chunk notice** — the bundle is ~1.19 MB (372 KB gzip) because ~5,000 questions are
   embedded inline. Harmless for an offline app loaded from `file://`; no network cost. Could be
   code‑split later if desired.
3. **Native haptics not wired** — `@capacitor/haptics` is installed but the game uses web sound
   (`AudioContext`) and does **not** call `navigator.vibrate`, so there is nothing to bridge. Pure
   enhancement opportunity, not a defect.
4. **`pod install` / Xcode Release archive were not executed here** — this preparation ran on
   **Linux**, which has no CocoaPods and no Xcode. The **web build is fully verified** (`npm run
   build` ✅, `tsc --noEmit` ✅, `cap sync` ✅). The CocoaPods install and the final Release/Archive
   compile must be run once on a Mac — exact commands in §6. The native project, signing
   placeholders, plist, pods spec, and asset catalogs are all generated and pre‑configured for that step.

## 6. Exact commands to run the project

> Requires a **Mac with Xcode 15 or 16** and **CocoaPods** (`sudo gem install cocoapods`).
> Node 18+ and npm are also required.

```bash
# 1. Install JS dependencies
npm install

# 2. Build the web app (produces dist/)
npm run build

# 3. Generate / refresh the native iOS project and install pods
npx cap sync ios          # copies dist → ios, runs `pod install` on macOS

# 4. Open the workspace in Xcode
npx cap open ios          # or: open ios/App/App.xcworkspace
```

Then in Xcode: select the **App** scheme → choose a Simulator or your connected iPhone →
set your **Team** (see §9) → press **Run** (⌘R). For the store: **Product ▸ Archive**.

Handy shortcuts (defined in `package.json`):
```bash
npm run ios:sync   # build + cap sync ios
npm run ios:open   # open the Xcode workspace
npm run dev        # run the game in a desktop browser for quick iteration
```
